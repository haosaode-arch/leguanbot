## 一、项目是什么

一个 **Telegram 群娱乐机器人**，围绕金币经济系统构建。

- 型号/代号：乐关 Bot（仓库 `leguanbot`）
- 开发语言：Python 3.12 + python-telegram-bot(v22 异步) + Flask(Web) + SQLite
- 运行方式：Docker 容器（部署在 Emby 服务器上）

## 三、账号与配置位置

| 项目 | 位置 |
|------|------|
| Bot token | 服务器 `.env`（`BOT_TOKEN=`）或本地 `token.txt`，**不入库** |
| Web 管理员 | 默认 `leguan / leguan123`，密码哈希在 SQLite `settings` 表 |
| Web 端口 | `8080`，环境变量 `WEB_PORT` 修改，`0` 关闭 |
| 代理 | 优先级：Web 面板保存 > 环境变量 `PROXY_URL` > 直连 |
| 数据库 | 容器卷 `/app/data/bot_data.db` ← 服务器宿主机 `./data/` |


## 五、部署与运维现状

- 仓库（私有）：https://github.com/haosaode-arch/leguanbot
- CI：push → Actions 自动 build → `ghcr.io/haosaode-arch/leguanbot:latest`（另有 `v<短提交号>` 可回滚）
- 服务器部署文件：`源代码/docker-compose.server.yml`（改动时勿忘同步 compose 镜像名）
- 更新三步：双击 `推送更新.bat` → 等 Actions 绿勾 → 服务器 `pull && up -d`
- 更新脚本每次会把当前源码快照进 `源代码/历史备份/<时间戳>/`

## 六、踩过的坑（防止再踩）

1. **点人功能失效** → 忘了在 BotFather `/setprivacy` Disable 或没给群管理员
2. **GHCR manifest 404** → 是 OCI index（多平台镜像），不是拉不到；Accept 头要带 `application/vnd.oci.image.index.v1+json`
3. **PowerShell 红字** → git/robocopy 用 stderr 打印进度，红字不等于失败
4. **首次 GHCR 包是私有的** → 若想匿名拉取，须到包设置里改 Public；反之设 private 后服务器要 `docker login ghcr.io`
5. **代理测试不通** → 代理在宿主机时容器里不能填 `127.0.0.1`，要填局域网 IP
